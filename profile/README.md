My main project is [bifrost-emu](https://github.com/sloppyman2567/bifrost-emu), an ARM64 user-mode emulator that can run Android Games and Linux Games on x86-64 Linux hosts. It's doing very well in terms of progress as of when this README.md was updated (2026-11-08). The reason I started bifrost-emu is because i was tired of using solutions like Waydroid + some proprietary emulation (.eg Google's libndk_translation) for my Android Games. It always felt like something was missing. I just can't describe it.. Maybe like freedom. But it caused me to start bifrost-emu in June this year initially using free coding agents like GLM, DeepSeek, free Codex, and really anything I could've got my hands on. I realized I wasn't making significant progress at all toward my ultimate Goal. Running Android Games on Linux without being tied to Proprietary solutions... 

Eventually i decided to get the free claim offer for OpenAI's Plus subscription in September which greatly accelerated bifrost-emu's progress a lot. Allowing it to finally run VkQuake, Neverball, Dhewm3 with minimal to none graphical errors (v1.5.5). I continued to prompt and optimize the Emulator before deciding to go toward my goal for 2.0.0-alpha.1, getting an Android Game to run on it. The target was SpongeBob: Krusty Cook-Off with Android 15 runtime. It was much harder than I expected. But soon I got it to boot, though it kept getting stuck on something in Asgard. After some time, i got it to get into gameplay. It was very laggy, optimized it and I got 2 Claude Pro Subscriptions in October. I canceled my OpenAI Plus Plan so they wouldn't charge me (they still did somehow). And a lot of work gone through those couple weeks, making the Emulator more performant, more correct. Now I'm focusing on fixing bugs and improving user-experience so it's less painful to install bifrost-emu on a different linux distro... Anyways that's all I have to say. Thanks for reading.
